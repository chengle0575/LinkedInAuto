Thanks for stopping by! If you're here, you're probably interested in automating the job application process.

This project was built during the TinyFish Hackathon. It allows users to manually log in to LinkedIn, search for jobs, and automatically "Easy Apply" to a listing on their behalf.

It's a small start, but there's plenty of room to grow.

### Known Limitations

1. Currently applies to only one job per session
2. Cannot handle listings without an "Easy Apply" option
3. Agent behavior could be more stable and resilient
4. No application status tracking yet

Contributions and ideas are more than welcome!
