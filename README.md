# LinkedInAuto
A tool used to automate job application in linkedin.
This project was built during the TinyFish Hackathon. It allows users to manually log in to LinkedIn, search for jobs, and automatically "Easy Apply" to a listing on their behalf.



# Quick questions

(1)How it works?
Upload your resume (PDF) and set job preferences (title, experience level, location)
The AI agent logs into LinkedIn, searches for matching jobs, and auto-fills applications using your resume data
You can monitor the entire process happen in real-time via a live browser preview

(2) Has it successfully applied to a job?
Yes! In the video below, it applied to a TikTok position via Easy Apply on my behalf. One small hiccup — it listed my gender as "Male" because I never specified it in my resume.

(3) Is it stable?
Not always, and that's something we need to improve. For instance, the agent sometimes takes too long to recognize that the user has already logged in.

(4) How does login work?
For now, you'll need to log in to LinkedIn manually and handle any bot detection (e.g. CAPTCHA) yourself
